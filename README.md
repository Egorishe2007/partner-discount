# Учебная практика

Проект учебной практики: настольное CRM-приложение менеджера по работе с
партнерами. Расчет индивидуального процента скидки, объемы продаж из базы
данных, реестр партнеров и карточка партнера с сохранением в базу.

Python 3.10, PostgreSQL 18, драйвер psycopg2, интерфейс на Tkinter.

## Структура

```
Учебная практика/
├── учебная практика_14.09.2026/
│   ├── Разработка ядра бизнес-логики (Расчет скидки)/
│   ├── Интеграция с БД и агрегация данных (SQL + Backend)/
│   ├── Разработка интерфейса (UI) по руководству по стилю/
│   └── Наполнение интерфейса, отладка и стресс-тестирование/
└── учебная практика_21.09.2026/
    ├── Проектирование многооконной архитектуры и навигации/
    ├── Разработка формы добавления-редактирования партнера/
    ├── Интеграция формы с БД (CRUD-операции и обновление UI)/
    └── Обработка исключений и интерактивные уведомления (UX-UI)/
```

Каждая папка задания самостоятельная: в ней лежит весь код, нужный для
запуска, и свой README с условием, решением, скриншотами и командами.
Папки идут по порядку заданий, и каждая следующая продолжает предыдущую.

Итоговая сборка проекта — в папке «Обработка исключений и интерактивные
уведомления (UX-UI)» за 21.09.2026.

В именах двух папок слеш из названия задания заменен дефисом: слеш в
имени каталога недопустим.

## Что сделано по заданиям

### Неделя 14.09.2026

| Задание | Результат |
| --- | --- |
| Ядро бизнес-логики | функция `calculate_partner_discount` и тесты границ 9999, 10000, 49999, 50000, 300000 |
| Интеграция с БД | подключение psycopg2, запрос с `LEFT JOIN` и `SUM(quantity)`, данные партнера с процентом скидки |
| Интерфейс по руководству по стилю | окно на Tkinter: логотип, иконка, заголовок, карточки партнеров |
| Наполнение интерфейса | реальные данные в карточках, пустая история продаж дает 0 %, приложение не падает без базы |

### Неделя 21.09.2026

## Запуск

```
pip install -r requirements.txt
psql -U postgres -c "CREATE DATABASE partners_db"
psql -U postgres -d partners_db -f schema.sql
python app.py
```

Пароль к базе берется из переменной окружения `DB_PASSWORD`, в коде он не
хранится.

## Тесты

В каждой папке задания:

```
python -m unittest -v
```

В итоговой сборке 68 тестов: расчет скидки, запросы к базе, переходы
между окнами, поля формы, сохранение карточки и диалоговые уведомления.
Реальная база для тестов не нужна — данные и диалоги подменяются
заглушками; на машине без графической оболочки оконные тесты
пропускаются.
