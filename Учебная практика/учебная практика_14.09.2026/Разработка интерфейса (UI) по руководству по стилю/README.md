# Разработка интерфейса (UI) по руководству по стилю

Экранная форма на Tkinter для менеджера компании: единое оформление,
логотип, заголовок и список партнеров.

Требования из ТЗ и как они выполнены:

- Заголовок окна — «CRM: Список партнеров и скидок».
- Уникальная иконка приложения в углу окна — `resources/icon.ico`.
- Логотип компании на главной форме — `resources/logo.png`.
- Главный макет — список карточек партнеров по руководству по стилю:
  «Тип | Наименование партнера», директор, телефон, рейтинг, а справа —
  процент скидки.
- Шрифты, цвета фона и кнопок собраны в `ui_style.py`: белый фон, тонкая
  серая рамка карточек, шрифт Segoe UI.

![Окно приложения](screenshot.png)

## Файлы

| Файл | Назначение |
| --- | --- |
| `app.py` | экранная форма: шапка с логотипом и список карточек |
| `ui_style.py` | цвета и шрифты из руководства по стилю |
| `resources/` | логотип компании и иконка приложения |
| `db.py` | подключение к PostgreSQL |
| `partner_service.py` | запросы к БД и расчет скидки |
| `partner_discount.py` | функция расчета скидки из задания 1 |
| `schema.sql` | таблицы и тестовые данные для базы |

## Запуск

```
pip install -r requirements.txt
psql -U postgres -c "CREATE DATABASE partners_db"
psql -U postgres -d partners_db -f schema.sql
python app.py
```

Если база недоступна, окно все равно открывается: список остается пустым, а
причина выводится в строке состояния внизу.
