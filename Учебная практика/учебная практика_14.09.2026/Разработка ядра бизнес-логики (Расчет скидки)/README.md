# Разработка ядра бизнес-логики (Расчет скидки)

Изолированная функция, которая рассчитывает индивидуальный процент скидки
партнера на основе суммарного объема купленной им продукции за весь период.

| Суммарный объем продукции | Скидка |
| --- | --- |
| менее 10 000 ед. | 0 % |
| от 10 000 до 49 999 ед. | 5 % |
| от 50 000 до 299 999 ед. | 10 % |
| от 300 000 ед. и более | 15 % |

Отрицательный объем считается ошибкой ввода: функция выдает `ValueError`.

## Файлы

| Файл | Назначение |
| --- | --- |
| `partner_discount.py` | функция `calculate_partner_discount` |
| `test_partner_discount.py` | unit-тесты граничных значений |

Код оформлен по PEP 8: имена в snake_case, в каждой строке одна команда.

## Запуск тестов

```
python -m unittest -v
```

Проверяются границы 0, 9999, 10000, 49999, 50000, 299999, 300000 и
отрицательное значение — всего 8 тестов.

## Покрытие тестами

pip install coverage
